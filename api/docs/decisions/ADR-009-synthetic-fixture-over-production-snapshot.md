# ADR-009. 테스트 픽스처는 운영 스냅샷이 아니라 합성 샘플로 둔다

- 날짜: 2026-08-06
- 상태: 확정
- 대체: [ADR-007](ADR-007-commit-export-snapshot-for-tests.md)

## 맥락

ADR-007은 fresh clone·CI에서 `classpath:data/export.json`이 없어 테스트가
깨지는 문제를 운영 데이터 107건을 그대로 커밋해서 풀었다. 그 결정은 두
전제를 달고 있었다.

1. "저장소가 private이고 ... 커밋에 따른 노출 리스크는 없다"
2. "브랜드 구성이 크게 바뀔 때마다 서버의 `data/export.json`을 다시 복사해
   커밋하는 습관이 필요하다 — 지금은 수동, 자동화 안 돼 있음"

둘 다 깨졌다. 저장소는 public이 됐고, 습관은 생기지 않았다. 2026-08-06에
확인했을 때 픽스처는 **2026-07-29에서 멈춘 107건, 13필드**였다. 그 사이
스키마는 16필드가 됐고(`expiresAt`·`badge`·`soldOut`), `DiscountTier`에도
`channel`·`soldOut`·`expiresAt`이 붙었다 — 픽스처엔 그중 무엇도 한 번도
나타나지 않았다.

ADR-007이 스스로 "대가 / 향후 조치"에 적어둔 위험이 그대로 실현됐다.
사람의 습관에 기대는 갱신은 안 일어난다.

## 판단

픽스처를 운영 데이터의 사본이 아니라 **스키마를 덮는 합성 샘플**로 바꾼다.
브랜드 6건이고, 크기가 아니라 덮는 범위를 기준으로 골랐다.

| 샘플 | 덮는 것 |
|---|---|
| bhc / baemin | 구간 없는 단순 오퍼 |
| bhc / ddangyo | `channel`로 갈린 별개 쿠폰(배달·포장) |
| 도미노피자 / coupangeats | `soldOut` 구간 + 대표값이 품절가가 아님 |
| 도미노피자 / baemin | 구간별 `expiresAt`(12-30 / 12-31) |
| 뚜레쥬르 / yogiyo | `percent` 정률+상한 구간 |
| 네네치킨 / yogiyo | `amount: null` → `status: held` |

`rawText`는 전부 `[샘플]`로 시작한다. 화면에 그 문구가 보이면 실데이터를
안 읽고 있다는 신호다.

## 근거

- **낡아도 안 깨지는 게 문제였다.** ADR-007의 테스트들은 "최소 1건 존재"만
  확인해서, 스냅샷이 아무리 낡아도 계속 통과했다. 합성 픽스처는 스키마가
  바뀌면 그 필드를 덮던 샘플이 곧바로 어긋나므로, 고쳐야 한다는 게 보인다.
- **픽스처는 데이터가 아니라 계약의 예시다.** 운영 데이터를 복사해 두면
  둘 중 하나다 — 매번 갱신하거나(안 했다), 조용히 낡거나(그랬다).
- **로컬 기본값이 무엇인지 드러난다.** 2026-08-03에 로컬에서 export.json을
  고쳐도 화면이 안 바뀌는 일이 있었는데, 원인이 이 classpath 기본값이었다.
  그때는 무엇을 보고 있는지 알 방법이 없었다 — 이제 `[샘플]`이 뜬다.
- 운영 배포는 영향 없다. ADR-001대로 `DISCOUNT_EXPORT_PATH`가 덮어써서
  이 파일을 읽지 않는다. `application.yml`도 `${DISCOUNT_EXPORT_PATH:...}`
  형태로 바꿔 환경변수 경로를 명시했다.

## 대가

- 로컬에서 앱을 띄우면 브랜드가 6개뿐이라 실제 화면 감을 볼 수 없다.
  실데이터를 보려면 `DISCOUNT_EXPORT_PATH`를 걸어야 한다 — 원래 그게
  정상 절차였고, 이제 기본값이 그 사실을 숨기지 않는다.
- 스키마가 늘면 픽스처도 손봐야 한다. 이건 대가가 아니라 목적이다.

## 곁가지

`.gitignore`의 `data/` 패턴이 `src/main/resources/data/`까지 잡고 있었다.
이미 추적 중인 파일이라 조용히 유지됐지만 `git add`가 거부된다 — `/data/`로
좁혀 런타임 디렉터리만 무시하게 했다.
