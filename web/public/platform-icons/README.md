# 배달앱 아이콘 위치

파일명 = platform 키 + `.png`. 4개 고정.

| 파일명 | 앱 |
|---|---|
| `baemin.png` | 배달의민족 |
| `coupangeats.png` | 쿠팡이츠 |
| `ddangyo.png` | 땡겨요 |
| `yogiyo.png` | 요기요 |

- **256×256 정사각, 바깥 여백 0으로 규격화한다.** 앱 아이콘의 둥근 모서리는
  투명 픽셀로 들어 있어야 한다 — 타이틀바 배지가 배경·테두리 없이 그림만
  꽉 채워 그리고, 서로 음수 margin으로 겹쳐 붙기 때문이다. 여백이 남아 있는
  원본은 알파 200 이상 영역으로 잘라내고 정사각으로 채운 뒤 256으로 줄인다
  (`_0` 접미사 파일은 그 원본이다).
- 없으면 앱 이름 첫 글자(배/쿠/땡/요)로 자동 대체되므로 아이콘 없이도 화면은 정상 동작한다.
