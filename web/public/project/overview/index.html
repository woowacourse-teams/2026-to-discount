기술 구조

폰 화면에서 웹까지
사람 손 없이 흐릅니다

배달앱은 할인 정보를 내주는 공개 통로(API)가 없어서 실제 폰 화면을 읽습니다.
앱 내부 통신은 쓰지 않고, 누구나 보는 화면만 읽습니다.

  1. 실제 폰3대USB로 연결한 폰이 배달앱 네 곳을 돕니다.
  3. 수집 PC하루 3회화면을 읽어 덧붙이기만 하는 원장에 쌓습니다.
  5. 서버24,365줄원장 기록입니다. 빠진 값이 없는지 검사한 뒤 배포합니다.
  7. 웹4개 앱브랜드마다 가장 큰 할인과 조건을 보여 줍니다.

Java와 Spring Boot 4.1입니다. 데이터베이스 없이 JSON 파일로 운영하고, Oracle Cloud에 자체 배포합니다.
