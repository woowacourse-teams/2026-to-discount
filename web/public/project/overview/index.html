기술 구조

폰 화면에서 웹까지 사람 손 없이 흐른다

배달앱은 할인 정보를 내주는 공개 통로(API)가 없어서 실제 폰 화면을 읽습니다. 앱 내부 통신은 쓰지 않고 누구나 보는 화면만 읽습니다.

  1. 폰 3대USB로 연결한 실제 폰이 배달앱 네 곳을 돈다
  3. 수집 PC하루 세 번 화면을 읽어 덧붙이기만 하는 원장에 쌓는다
  5. 서버빠진 값이 없는지 검사한 뒤 배포하고 다시 읽는다
  7. 웹브랜드마다 가장 큰 할인과 조건을 보여 준다
