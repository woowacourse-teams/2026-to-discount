시행일 2026-11-12

1. 처리하는 정보와 목적

어떤 화면이 실제로 쓰이는지 보려고 방문 통계를 씁니다. 하나는 직접 만든 익명 통계로 자체 서버에 기록하고, 같은 화면 행동을 제품 사용 흐름 분석을 위해 브라우저에서 PostHog로 직접 전달합니다. 자체 서버에는 IP 원본을 저장하지 않고, PostHog에는 이름·연락처를 보내지 않으며 쿠키도 사용하지 않습니다. 검색을 개선하려고 검색창에 입력한 검색어와 그 결과도 함께 기록합니다.

배포 플랫폼의 쿠키 없는 집계형 통계(Vercel Analytics)도 페이지뷰 수준으로 사용하며, 이 통계들은 광고 목적으로 쓰지 않습니다.

방문 통계에 담기는 항목

  • 방문자 ID(이 브라우저가 만든 난수), 세션 ID, 방문 횟수
  • 본 화면 경로, 체류 시간, 누른 항목, 선택한 필터, 검색어와 결과
  • 기기 구분(데스크톱/모바일)과 화면 크기, 홈 화면에 설치해 열었는지, 카카오톡 인앱 브라우저인지(참/거짓만)
  • 유입 구분(직접/사이트 내부/외부). 유입 주소 원본은 받지 않습니다.
  • 실사용 성능(Web Vitals: LCP, INP, CLS, TTFB)과 오류 보고(오류 종류, 메시지 120자 이내, 발생한 컴포넌트 이름). 페이지당 오류는 5건까지 보냅니다.

User-Agent 원문은 자체 서버에 저장하지 않습니다. 다만 요청이 스스로 밝힌 크롤러(검색 로봇)는 이름만 가려 표시합니다. 검색어 속 긴 숫자열(전화번호, 카드번호 등)은 #으로 가립니다. PostHog에는 SDK 기본 기기·브라우저 속성(Android 기기 모델 포함)과 Web Vitals도 함께 갑니다. 세션 녹화, 자동 클릭 수집, 설문, 예외 자동 수집은 켜지 않았습니다.

IP 주소

자체 서버는 IP 원본을 저장하지 않습니다. 같은 날 중복·과다 요청을 가리려고 IP를 서버를 켤 때마다 새로 만드는 난수 솔트와 날짜로 SHA-256 해시해 앞 8바이트만 이벤트 기록에 남깁니다. 솔트는 디스크에 저장하지 않아 날짜가 바뀌거나 서버를 다시 켜면 이어지지 않고, 해시에서 IP를 되살릴 수 없습니다. 요청 횟수 제한에 쓰는 카운터는 서버 메모리에만 있습니다. PostHog와 GA4는 각 서비스가 요청을 받으면서 IP를 처리합니다(GA4는 IP 익명화를 켰습니다).

잘못된 정보 제보

"잘못된 정보 제보"로 보낸 제보 내용(최대 500자), 유형, 앱, 브랜드, 화면 주소, 필터, 방문자 ID를 자체 서버 파일에 저장하고 운영 슬랙으로 전달합니다. 요청 제한용 IP 해시도 함께 남습니다. 이름·연락처는 받지 않으니 제보 내용에 쓰지 마세요.

2. 웹 푸시 알림

알림을 켠 경우에만 처리합니다. 알림은 브라우저가 허용을 물은 뒤 켜집니다.

  • 서버에 저장하는 값: 브라우저가 발급한 구독 주소(endpoint)와 암호화 키(p256dh, auth), 방문자 ID, 방문 통계 허용 여부(analyticsEnabled), 등록·갱신 시각, 활성 여부. 구독 주소는 알림을 보내는 데 필요합니다.
  • 알림 표시·클릭 추적: 알림마다 추적 토큰을 발급해(유효 30일) 알림이 표시되고 눌렸는지를 한 번씩 기록합니다. 구독 시 방문 통계를 허용한 경우에만 방문자 ID와 함께 방문 통계에 남깁니다. 브라우저에서 추적 안 함(DNT/GPC)이 켜진 채 구독하면 이 기록은 남기지 않습니다.
  • 해지: 설정에서 알림을 끄면 브라우저 구독을 해지하면서 서버에 저장한 구독 정보(구독 주소, 키, 방문자 ID)를 삭제합니다. 브라우저에서 알림 권한을 직접 끌 수도 있습니다. 보내려다 허용되지 않는 구독 주소로 확인된 구독은 비활성으로 바뀝니다.

3. 쿠키와 브라우저 저장소

자체 통계와 PostHog는 쿠키 대신 브라우저 저장소(localStorage, sessionStorage)를 씁니다. 이 값은 내 브라우저에만 있고 사이트 데이터를 지우면 사라지며, 지우면 방문자 ID가 끊깁니다.

  • 식별·통계: 방문자 ID, 방문 횟수, 개발 트래픽 표시, 이번 세션 ID(탭을 닫으면 사라짐), 주소 ?from= 유입 값, 공유 링크 유입 기록, PostHog SDK 상태
  • 설정·편의: 최소 금액 필터, 숨긴 브랜드, 브랜드 좋아요/싫어요, 홈 화면 시안 배정, 첫 방문 안내와 배너·말풍선을 봤거나 닫았는지, 쿠팡이츠 안내를 본 적 있는지, 알림 사용 여부와 알림 안내 노출 기록, 설문 참여·닫음 기록
  • 세션 임시값: 배달앱으로 나간 시각(돌아왔는지 보려고), 브랜드 노출 기록, 화면 새로고침 시각, 설문 시험 정보

재방문 여부를 더 정확히 보려고 Google Analytics(GA4)를 임시로 함께 사용합니다. 위 통계와 달리 쿠키(_ga)를 사용하며 데이터가 Google로 전달됩니다. 저희 쪽에서 광고 개인화·Google Signals는 껐고 IP 익명화를 켰습니다. 트래픽 정확도 확보를 위한 임시 조치이며 목적을 달성하면 제거할 예정입니다.

4. 이용하는 외부 서비스

  • PostHog: 화면 행동 분석. 브라우저와 서버가 같은 이벤트를 보냅니다(방문자 ID로 묶음).
  • Google Analytics(GA4): 재방문 측정(임시). 쿠키 사용.
  • Vercel Analytics: 쿠키 없는 페이지뷰 집계. 이 사이트의 호스팅도 Vercel입니다.
  • Slack: 잘못된 정보 제보를 운영자에게 알리는 데만 씁니다.
  • 브라우저 푸시 서비스: 알림을 켜면 Google, Apple, Mozilla 등 브라우저 제공자의 푸시 서버로 알림이 전달됩니다.

이 서비스들을 광고 목적으로 쓰지 않습니다.

5. 보관 기간

방문 통계와 검색어 기록은 3개월 보관한 뒤 지웁니다.

6. 거부하는 방법

브라우저의 추적 안 함(DNT/GPC) 설정이 켜져 있으면 위 통계와 GA4를 모두 보내지 않습니다. 브라우저 설정에서 쿠키를 차단하거나 사이트 데이터를 지워도 됩니다. 알림은 설정에서 끄면 서버에 저장한 구독 정보가 삭제됩니다. 거부해도 할인 목록은 그대로 쓸 수 있습니다.
