# ADR-004. 개발 및 운영 API origin의 환경별 지정

- 날짜: 2026-10-12
- 상태: 승인 및 구현, 배포 설정 대기

## 전제

기존 ADR-001의 백엔드 하나라는 전제가 개발 API 추가로 바뀌었다. 개발 웹에서도 운영 API를 호출하면 개발 데이터를 검증할 수 없다.

## 결정

VITE_API_BASE_URL을 브라우저 및 SSR 빌드에 주입하고 사전 렌더링에서도 같은 설정과 검증 함수를 사용한다. 초기 배너 요청도 Vite HTML 변환으로 같은 origin을 사용한다. 개발 배포는 VITE_APP_ENV=development에서 지정된 개발 API만 허용하고 설정 누락이나 운영 주소는 빌드를 실패시킨다.

운영의 기존 기본값은 유지한다. API는 계속 절대주소로 직접 호출하며 Vercel /api 프록시를 만들지 않는다. API 장애 시 개발 배포가 운영 데이터로 대체되지 않는다.

## 근거와 한계

환경변수가 누락되어 프론트 자신의 상대경로로 요청하던 과거 문제는 origin 검증과 개발 빌드 실패로 막는다. 브라우저 변수는 공개되므로 비밀정보를 넣지 않는다. 빌드 설정을 변경하면 재배포해야 한다.
