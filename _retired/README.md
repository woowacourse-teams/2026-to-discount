# 불용 자산 보관

더는 어떤 코드도 참조하지 않는 파일을 여기 둔다. **지우지 않는다** — 지운
파일은 되살릴 수 없지만, 안 읽는 파일은 `web/public/` 밖에 있는 한
해가 없다.

옮길 때는 이 문서에 한 줄을 남긴다: **무엇을 · 언제 · 왜.**

## 보관 목록

### `logos/유가네찜닭.png` — 2026-09-07 수납

`web/public/logos/`에 있던 파일. `brands.yml`의 표제어가 `유가네닭갈비`로
바뀌었는데(별칭에 `유가네찜닭`이 남아 있다) 로고 파일명은 옛 이름 그대로
있었다. 프론트는 표제어(`brandLogoSrc`가 만드는 파일명)로만 로고를
찾으므로, 별칭이 있어도 이 파일은 **화면에 한 번도 뜬 적이 없다** —
사용자가 "유가네닭갈비는 alias 있을텐데 로고 없음으로 뜨네?"라고 지적한
바로 그 증상이다.

대신 같은 브랜드 딥링크 순회 스크린샷에서 로고를 새로 오려
`web/public/logos/유가네닭갈비.png`로 채웠다(`scripts/extract_brand_logos.py`,
tracker 저장소). 그림 자체는 다르지 않다 — 화면에 뜨는 이름으로 옮긴 것뿐.
