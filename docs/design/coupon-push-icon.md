# 쿠폰 화면 알림 아이콘 복구

## 문제와 목표

쿠폰 화면의 상단에 알림 버튼 자리가 없고 기존 위치를 한 번만 조회하여 A/B 화면 전환 후 연결이 끊긴다. 두 화면에서 기존 알림 설정을 사용할 수 있도록 한다.

## 범위와 설계

상단 바별 버튼 자리를 callback ref로 App에 전달하고 알림 설정은 현재 자리에 렌더링한다. DOM을 한 번 검색하거나 변경을 감시하는 방식보다 실제 마운트와 제거 시점에 위치를 갱신한다. 발송 정책과 안내 문구는 변경하지 않는다.

## 완료 조건과 검증

home=a와 home=old에서 알림 아이콘이 보이고 초기 A/B 전환 이후에도 유지된다. 브라우저에서 두 화면 표시를 확인하고 npm test, npm run build, git diff --check를 실행한다.
