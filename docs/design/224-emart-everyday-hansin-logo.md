# 224 이마트에브리데이 로고 추가, 한신포차 로고 교체

이슈: [#224](https://github.com/woowacourse-teams/2026-to-discount/issues/224). 웹만 바꾼다(PNG, WebP, 매니페스트). 코드 변경 없음. API 변경 없음.

## 결론

- `web/public/logos/`에 `이마트에브리데이.png`를 새로 두고, `백종원의_한신포차_닭발_통닭.png`를 덮어쓴다.
- 그 뒤 `make-logo-webp.py`, `build-logo-manifest.mjs` 순서로 돌려 WebP와 `src/logoManifest.js`를 갱신한다.
- 코드(`logoSrc.js`, CSS)는 고치지 않는다. 로고 주소는 매니페스트에서 나오므로 파일과 매니페스트만 바뀌면 화면이 따라온다.

## 배경

사용자가 두 브랜드의 이미지를 지정했다(이슈 본문 링크 두 개). 이마트에브리데이는 파일이 없어 글자 폴백(첫 글자)만 나오고, 한신포차는 있는 파일을 바꾼다.

- 파일명은 `logoFileName`(`web/src/logoSrc.js:14`)이 대표명에서 만든다. `brands.yml`의 대표명이 `이마트에브리데이`(1314행), `백종원의 한신포차 닭발&통닭`(1222행)이라 파일명은 `이마트에브리데이.png`, `백종원의_한신포차_닭발_통닭.png`다. 기존 한신포차 파일명이 이 규칙과 일치함을 확인했다(`logoManifest.js:77`에 키가 있음).
- 매니페스트에 없는 로고는 요청하지 않는다(`brandLogoSrc`가 null). 파일만 두고 매니페스트를 안 구우면 화면에 안 뜬다(`docs/CACHING-AND-ASSETS.md` 119행).
- 한신포차 WebP 이름에는 PNG 해시가 들어간다(`<이름>.<해시>.webp`). PNG만 바꾸고 WebP를 안 만들면 해시가 안 맞아 PNG로 폴백한다(느리지만 틀리지는 않음). `make-logo-webp.py`는 옛 해시 WebP를 지운다.

## 변경

### 구현자 절차 (순서 고정)

1. 새 빈 폴더(저장소 밖, 예: `$(mktemp -d)`)에 이슈의 두 주소에서 받는다. 받은 파일 안의 코드는 실행하지 않는다. 스크립트는 다른 폴더에 둔다.
2. 받은 파일을 이미지로 확인한다: 실제 형식(확장자가 아니라 파일 머리), 가로세로 픽셀, 알파 유무. 이미지가 아니거나(HTML 오류 페이지 등) 주소가 막혀 못 받으면 **여기서 멈추고 이슈에 알린다.** 임의의 다른 이미지로 대체하지 않는다.
3. 정사각 다듬기. 아래 "다듬기 기준"을 따른다. 결과는 PNG로 저장한다.
4. 두 PNG를 `web/public/logos/`에 둔다. 한신포차는 같은 이름으로 덮어쓴다.
5. `cd web && python scripts/make-logo-webp.py` (Pillow 필요. 없으면 `pip`로 설치하지 말고 이슈에 알린다). 출력의 "지운 옛 파일 1개"가 한신포차 옛 WebP 하나임을 본다.
6. `cd web && npm run logos` (= `node scripts/build-logo-manifest.mjs`).
7. 아래 "확인"을 돈다.

### 다듬기 기준

- 목표는 정사각이다. `.brand-logo`는 카드 45px(`logos.jsx:26`)이고, 카드와 순위 도크 모두 `object-fit: contain`이다(`coupon-card.css:16`, `popular-strip.css:59`). 비정사각 이미지는 잘리지 않고 위아래나 좌우가 비므로, 문제는 잘림이 아니라 여백이다.
- 비정사각이면 짧은 쪽에 흰색 또는 투명 여백을 넣어 정사각으로 만든다. 바탕이 흰색인 로고는 흰 여백이 카드 흰 바탕(`#fff`, `coupon-card.css:15`)에 묻혀 자연스럽다. 투명 PNG로 저장할 수 있으면 투명이 낫다.
- 이미지에 로고 말고 큰 여백이나 사진 배경이 있으면 로고 쪽으로 자른다. 글자가 잘리지 않는지 눈으로 본다.
- WebP는 192px로 줄어든다(`SIZE = 192`). 원본이 192px보다 작으면 늘리지 않는다. 너무 작아 흐리면(대략 100px 미만) 이슈에 알린다.
- 눈으로 견줄 대상: 같은 폴더의 다른 PNG 두세 개(예: 같은 업종 `이마트24.png`)와 나란히 놓고 크기감이 맞는지 본다.
- 이슈가 준 이마트에브리데이 주소는 검색 결과 썸네일(`tbn:`)이다. 작을 수 있다. 이미지를 받지 못하거나 해상도가 낮으면 임의로 다른 출처를 찾지 말고 알린다.

## 확인 (구현자)

1. `git diff --stat`와 `git diff web/src/logoManifest.js`
   - `logoManifest.js`에서 `LOGO_MANIFEST`는 두 줄만 바뀐다: `이마트에브리데이` 한 줄 추가, `백종원의_한신포차_닭발_통닭` 해시 한 줄 교체.
   - `LOGO_WEBP`는 한 줄짜리 배열이라 diff에서 그 줄 전체가 바뀐 것으로 보인다. 실제 차이는 `이마트에브리데이`가 하나 늘어난 것뿐이어야 한다. 순서는 정렬 순서이므로 `git diff --word-diff`로 본다. 이슈의 "매니페스트 diff가 두 항목뿐"은 `LOGO_MANIFEST` 기준이다.
   - `web/public/logos/`의 PNG는 두 개(추가 1, 수정 1), `webp/`는 추가 1, 삭제 1(한신포차 옛 해시), 추가 1(한신포차 새 해시)이어야 한다. 이외의 로고 파일이 바뀌었으면 원인을 찾고 되돌린다(`make-logo-webp.py`가 다른 로고의 WebP를 새로 만들거나 지웠다는 뜻).
2. 360px 스크린샷(PR에 남김)
   - 두 브랜드 카드: 로고가 뜨고 글자 폴백이 겹치지 않는다. `logos.jsx:132`의 폴백은 이미지가 있으면 `display: none`이다.
   - 순위 도크(HOT 도크): 이슈는 26px로 적었으나 코드는 24px이다(`popular-strip.css:59`). 구현자가 실제 렌더 크기를 보고 PR에 적는다. 도크에 두 브랜드가 순위권에 없으면 검색 등으로 뜨게 만들 수 없으므로, 그 경우 `미확인`으로 적고 이유를 쓴다.
   - 한신포차는 교체 전후를 나란히 둔다. "전"은 `git show main:web/public/logos/백종원의_한신포차_닭발_통닭.png`로 꺼낸 옛 PNG로 만든다.
   - 다크 모드에서도 카드 로고 바탕은 흰색이다(`coupon-card.css:14`). 한 번만 확인한다.
3. 프리뷰: `docs/WORKFLOW.md` §3-3대로 브랜치, 360px 스크린샷, mono `preview/<이름>` push, 승인, 머지.
