# 덤프 방식 가설과 실험 대장 (2026-11-11 14시 기준)

상위 이슈 [#248](https://github.com/nn98/delivery-discount-tracker/issues/248). 결과는 [경과 보고](2026-11-11-dump-way-progress.md), 목차와 분업은 [색인](2026-11-11-dump-way-index.md). 이 문서는 **어떤 가설이 확정, 기각, 진행 중인지와 어떤 실험이 끝났고 어떤 실험이 남았는지**를 한 표로 모은 것이다. 세션(WSL, sub, main)이 같은 상태를 보게 하려는 문서라서, 새 결과가 나오면 여기 표를 먼저 고친다.

상태 표기: **확정**(실기와 코드로 확인), **기각**(실험으로 틀림), **진행**(검증 실험이 준비되거나 돌고 있음), **추정**(근거 있으나 직접 확인 못 함), **교란**(다른 원인과 섞여 이 결과로 못 가름).
