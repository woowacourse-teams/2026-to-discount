# 쿠팡이츠 허브 제목의 기대값

수집 로그의 `읽힌 허브 제목 N개가 기대값(이 문서)과 다릅니다` 줄이 가리키는 문서다. 3단계가 허브 화면의 구역 제목을 OCR로 읽고, 아래 꼴과 맞는 제목만 판정에 쓴다. 맞지 않으면 카드 글자로 판정하므로 오퍼를 잃지는 않는다.

## 쓰는 제목

| 쓰임 | 기대하는 꼴 | 예 | 코드 |
|---|---|---|---|
| 릴레이 카드의 여는 시각 | `선착순` 뒤 12자 안에 `오전/오후 N시` 와 `오픈` | `선착순 할인 오후 5시 오픈` | `capture/coupangeats_hub_relay.py` `RELAY_TIME_RE` |
| 월간 쿠폰 카드 표시 | `월간 쿠폰` 또는 `월 1회` | `오직 WOW 와우회원만 드려요 브랜드별 월 1회 사용` | 같은 파일 `MONTHLY_HEADER_RE` |

## 기대값과 달라도 정상인 제목

허브에는 위 두 가지 말고도 구역 제목이 있다. 시각이 없는 것이 맞다. 코드(`capture/coupangeats_hub_relay.py` `KNOWN_HEADERS`, `known_header`)가 앞의 `응원석 N열`을 떼고 아래 열쇠말과 부분 일치로 보아, 맞으면 경고를 내지 않는다(2026-11-07부터, 그 전에는 이 제목들에도 회차마다 수십 번 떴다). 새 정상 제목이 생기면 열쇠말을 더한다.

| 제목(로그와 화면에서 본 것) | 열쇠말 |
|---|---|
| `응원석 1열 오늘의 위클리 슈퍼딜` | `위클리`, `슈퍼딜` |
| `응원석 2열 망설이면 종료되는 혜택! 반짝핫딜` | `망설이면`, `반짝핫딜` |
| `응원봉 대신 윙봉! 치킨 존 응원석 3열` | `윙봉`, `치킨 존` |
| `오직 이츠에서 선착순 할인 중` | `선착순 할인 중` |
| `이번 주는 장볼 때도 혜택이 가득!` | `장볼 때` |
| `피자/버거 브랜드 할인`, `기타 브랜드 할인` | `브랜드 할인` |
| `KFC 랜덤박스` 같은 카드 머리 | `랜덤박스` |

2026-11-02~04 로그와 11-07 화면(V30 증거 `coupangeats_promotion_unreached-20261107-055635.png`)에서 모았다.

OCR 원문의 `B十飜十하디`, `trfr`, `lick`, `卜0` 같은 글자는 제목 옆 아이콘과 그림 글자를 읽은 잡음이다.

## 원문 보기

로그에는 원문을 찍지 않는다. 손으로 돌릴 때 `HUB_OCR_DEBUG=1`을 주면 `OCR 원문:` 줄이 같이 나온다.

## 언제 의심하나

릴레이 행사가 있는 날(허브에 `선착순 … 오픈` 제목이 보이는 날)인데 이 줄만 뜨고 릴레이 카드의 여는 시각이 비면, 제목 꼴이 바뀐 것이다. 그때는 `RELAY_TIME_RE`를 새 꼴에 맞추고 시험을 더한다.
