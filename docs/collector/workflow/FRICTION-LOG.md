## 같은 뿌리로 묶은 개선 방향

1. **조용한 skipped를 없앤다.** 명령을 못 알아들으면 "인식 못 함: 본문=…" 한 줄을 이슈에 남긴다.
2. **상태를 기계로 둔다.** 푸시 뒤 재리뷰(#210), 로컬 구현 push 전 fetch(#74), 종료 이유 로그, tracker CI 실패 슬랙 알림.
3. **새 저장소를 연결할 때 점검표를 스크립트로** 돌린다(App 설치, 시크릿, `GH_REPO`). 이슈 없는 PR은 PR 템플릿의 이슈 링크로 막는다.
4. **자동 판정이 막을 일은 처음부터 사람 명령 한 블록으로 넘긴다.** 병합, 권한 부여, 서버 쓰기. 자주 쓰는 `gh issue comment`, `gh pr comment`는 허용 규칙으로 올린다(사용자 몫).
5. **"문서만"인 것 중 사용자가 두 번 이상 지적한 것부터 훅이나 CI 검사로 올린다.**
6. **로고처럼 사용자가 핫픽스로 분류한 변경**은 PR 없이 main에 바로 적용한다(mono `AGENTS.md` 예외, 2026-11-01). 설계 건너뛰기는 별도 표식으로 명시한다.
