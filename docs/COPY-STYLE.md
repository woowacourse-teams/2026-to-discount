# 사용자에게 보이는 문구 규칙 (2026-09-19)

웹 화면에 그대로 나가는 글자 전부에 적용한다. 원장의 `conditions`와 `badge`, 배너의 `amount`·`period`·`extra`·`event`·`note`, 웹 컴포넌트의 라벨과 버튼, 슬랙이 아닌 모든 사용자 화면. 지키는 코드는 이 문서 끝에 있다.

## 1. 원칙

1. 앱이 쓰는 말로 쓴다. 배민, 쿠팡이츠가 쿠폰 옆에 적는 것과 같은 길이와 말투.
2. 명사구 또는 짧은 조건 하나. 문장을 쓰지 않는다. `다.`, `요.`, `입니다`로 끝나지 않는다.
3. 설명, 근거, 날짜, 출처를 적지 않는다. "왜 이 값인가"는 코드 주석과 문서에 적는다.
4. 수집기의 말을 쓰지 않는다. 확인, 대조, 표기, 파서, 미확인, 관측, 수집, 판독, 추정, 실측, 정정 같은 말은 개발자끼리의 말이다.
5. 모르면 비운다. 모른다는 사실을 문구로 적지 않는다. 빈 칸은 화면이 "미확인"으로 그린다.
6. 30자 안. 배너 `extra`만 브랜드 나열 때문에 길어질 수 있다.

## 2. 칸마다 형식

| 칸 | 형식 | 예 | 금지 |
|---|---|---|---|
| `conditions` | 조건 하나 또는 쉼표로 둘 | `1일 1회, 배달만` / `매일 랜덤 뽑기` / `특정 메뉴 한정` / `18,000원 이상` | `뽑기 쿠폰. 받는 값이 사람마다 다르고 매일 다시 뽑는다(허브 랜덤 표기, 쿠폰함 대조)` |
| `badge` | 멤버십이나 표식 한 단어 | `배민클럽` / `쿠팡와우 전용쿠폰` / `5%할인` | `쿠팡와우 회원 전용(일반 회원 화면엔 안 뜬다, 2026-09-03 실측)` |
| 배너 `amount` | 금액 문구 하나 | `8,000원` / `6/5/8천원` / `최대 7,000원` / `1,000/2,000원 중복할인` | `최대 8,000원(랜덤이라 다를 수 있음)` |
| 배너 `period` | 기간 또는 시각 한 조각 | `9월 18일 하루` / `매일 오전 11시 오픈` / `~9/30` | `9월 18일까지 진행되는 행사입니다` |
| 배너 `extra` | `[행사] / [조건], [한정], [채널]` 또는 브랜드 나열 | `뚜쥬데이 / 18,000원↑, 사용(발급X) 선착순` / `10시~ 버거킹 · 11시~ 본도시락` | `선착순인데 배너에 없어 올림` |
| 배너 `event` | 행사 이름 | `위클리 슈퍼딜` / `뚜쥬데이` | |
| 배너 `note` | 조건 한 조각 | `특수매장 제외` | `사람이 확인 필요` |

배너는 구조 필드(설계 31)를 적으면 서버가 이 형식으로 문구를 만든다(`BannerText`). 문장 칸은 그 형식이 안 맞을 때만 손으로 적는다.

## 3. 새 문구가 필요할 때

세션(AI)이 사용자에게 보이는 새 문구를 만들어야 하면 넣기 전에 개발자에게 두 가지를 묻는다. 그 자리에 문구가 들어가는 것이 맞는지, 그리고 어떤 문구인지. 개발자가 답하기 전에는 비워 둔다.

## 4. 지키는 코드

- 원장: `schema.validate_record(..., user_facing_copy=True)`가 ingest에서 `conditions`, `badge`를 검사한다. 30자 초과, 문장 끝, 4번 단어 → 거부. `tests/test_schema.py`.
- 배너: `BannerSpec`이 구조 필드에서 문구를 만든다. `ops_apply.py`(콘솔 편집기와 제안 반영)가 문장 칸에 같은 검사를 건다.
- 배포: `check_deploy.py`는 위 규칙에 어긋난 옛 `conditions`가 사라지는 것을 손실로 세지 않는다.
- 이 문서를 고치면 위 세 코드의 단어 목록도 같이 고친다.

## 5. 왜 생겼나

2026-09-03, 09-07, 09-18에 수집기의 근거 문장이 `conditions`로 웹 카드에 그대로 나갔다. 세션이 "왜 이 값인지"를 적을 자리를 사용자 칸에서 찾았다. tracker `docs/HARNESS.md` §13.
