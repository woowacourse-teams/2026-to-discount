# 메인 화면 A/B 변경 기록

메인 화면 A/B(운영 카드 `old` / 쿠폰 카드 `coupon`)의 두 안 중 하나라도 바뀐 시각을 적는다. 집계는 이 시각을 경계로 나눈다. 시각은 한국 시각이고, "운영 반영"은 웹 미러 배포 워크플로가 끝난 시각이다.

- 배정: 2026-10-05 00:00부터 방문자 ID 해시로 반반(`web/src/homeExperiment.js`). 그 전에는 모두 `old`.
- 이벤트마다 `props.home`(old 또는 coupon)이 실린다. 주소로 강제한 방문(`?home=a`, `?home=old`)은 `props.home_forced = "1"`이라 집계에서 뺀다.
- 쿠폰 카드 쪽은 서버 렌더 첫 화면이 운영 카드라, 마운트 뒤 쿠폰 카드로 바뀐다. 최대 콘텐츠 표시 시간(LCP)과 누적 레이아웃 이동(CLS)은 이 점을 감안해 읽는다.
