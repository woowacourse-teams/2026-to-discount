# 메인 화면 A/B 변경 기록

메인 화면 A/B(운영 카드 `old` / 쿠폰 카드 `coupon`)의 두 안 중 하나라도 바뀐 시각을 적는다. 집계는 이 시각을 경계로 나눈다. 시각은 한국 시각이고, "운영 반영"은 웹 미러 배포 워크플로가 끝난 시각이다.

- 배정: 2026-10-05 00:00부터 방문자 ID 해시로 반반(`web/src/homeExperiment.js`). 그 전에는 모두 `old`.
- 이벤트마다 `props.home`(old 또는 coupon)이 실린다. 주소로 강제한 방문(`?home=a`, `?home=old`)은 `props.home_forced = "1"`이라 집계에서 뺀다.

## 2026-10-17 결론: 쿠폰 카드로 통일

2026-10-17 사용자 결정으로 메인 화면 비교 실험을 끝내고 모든 방문자에게 쿠폰 카드 안을 보인다. 운영 카드 안은 `?home=old`로만 연다.

명세(tracker `docs/superpowers/specs/2026-10-02-home-a-design.md` 6절)의 판정 규칙은 "리텐션이 나빠지지 않고 오퍼 클릭률이 오르면 A(쿠폰 카드) 채택, 최소 2주"다.

- 오퍼 클릭률(링크 클릭): 쿠폰 카드 33.1%, 기존 카드 27.5%(+5.6%p, 상대 +20%, z +2.53). 첫 방문 안내를 뺀 뒤도 41.6%와 33.5%(z +2.14)로 같은 방향이다.
- 리텐션(2일 이상 재방문): 24.8%와 24.9%(z -0.07). 나빠지지 않았다.
- 기간: 2026-10-05 00:00 ~ 2026-10-17 04:00, 12일 남짓이다. 최소 2주에 하루 모자란다. 사용자가 이 상태로 결정했다.
- 1·2·4주 리텐션은 아직 재지 않았다. 2일 이상 재방문으로 대신했다.

### 집계 기준

- 숫자는 PostHog(행동 분석 서비스)에서 2026-10-17 04시에 냈다. 원장(`events.jsonl`)은 로컬 사본이 2026-10-14 15:44까지라 전 기간을 원장으로 낼 수 없었다. 서버에서 새로 받으려면 ssh가 필요해서 받지 않았다.
- PostHog 숫자가 원장과 맞는지 2026-10-05 ~ 2026-10-14 15:44 구간으로 대조했다. 방문자(쿠폰 638 / 기존 603, 원장 653 / 613), 검색(11.3% / 5.0%, 원장 11.2% / 4.7%), 전환(30.1% / 26.0%, 원장 29.9% / 25.6%)이 같은 방향, 같은 크기다.
- 뺀 방문자:
  - 주소로 안을 강제한 방문자(`home_forced`)
  - 서버가 자동 방문으로 표시한 방문자(PostHog `bot` 속성: naver, headless, bingbot, daum, googlebot 등)
  - 원장에서 개발 접속(`dev`)으로 표시된 방문자 1,409명. PostHog에는 `dev` 속성이 없어 원장 사본의 목록으로 뺐다. 2026-10-14 15:44 뒤에 처음 온 개발 접속은 빠지지 않았을 수 있다.
  - 배포 점검용(`v_deploycheck`)과 자동 방문자 1명(`v_fa46ff74d778e5ba`)
- 방문자의 안은 그 방문자 이벤트에 마지막으로 실린 `home` 값이다. 기기는 PostHog `$device_type`이 `Desktop`이면 컴퓨터, 나머지는 폰이다(원장 `device`는 일부 안드로이드를 컴퓨터로 잡아 쓰지 않았다).
- 지표 정의는 [HOME-AB-20261014.md](HOME-AB-20261014.md) 상세 1과 같다. 무동작에서 동작으로 치지 않는 이벤트는 화면·배너 노출, 들어옴과 나감, 성능 측정, 첫 방문 안내, 설문 노출, 알림 안내(보임, 닫힘, 표시), 앱 열림 결과와 복귀다.
- 차이는 쿠폰 카드 비율에서 기존 카드 비율을 뺀 값(%p), 상대 차이는 쿠폰 카드 비율 ÷ 기존 카드 비율 - 1이다. z 절댓값 1.96 이상이면 우연일 확률이 5% 아래다. 지표 일곱 개와 기기별 표를 함께 봐서 하나쯤은 우연히 1.96을 넘을 수 있다.

### 읽는 법

- 쿠폰 카드는 링크 클릭과 검색이 높고, 필터와 분류 사용이 낮다. 검색 칸이 늘 보이고 분류 바가 필터 일부를 대신하는 상단 바 구조 때문으로 본다(2026-10-08 현황과 같은 해석).
- 폰만 보면 링크 클릭 차이는 +3.8%p(z +1.59)로 유의하지 않다. 전체의 유의함에는 컴퓨터 방문자(+18.5%p)의 몫이 크다.
- 첫 방문 안내를 뺀 뒤 쿠폰 카드의 배너 클릭이 낮다(3.2% / 7.0%, z -2.23). 2026-10-15부터 배너를 목록 3번째 카드 뒤로 옮긴 변경이 쿠폰 카드에만 들어간 영향으로 보인다. 확인하지 않았다.
- 컴퓨터 방문자 재방문은 기존 카드가 높다(29.1% / 15.6%, z -2.37). 안마다 100명 남짓이라 결정에 넣지 않았다.
- 쿠폰 카드 안은 실험 중에 크게 바뀌었다. 숫자는 마지막 모습의 효과가 섞인 값이다.
