# 배너 순서(priority)가 노출과 클릭에 주는 효과

재현: `python scripts/banner_order_analysis.py` (PostHog와 배너 보관 파일이 있으면 언제든 다시 낸다)

## 결론

| 질문 | 답 | 확실한가 |
| --- | --- | --- |
| 순서가 노출을 바꾸나 | 바꾼다. 같은 시각 1번 칸 노출을 1로 두면 2번 칸 0.50, 3번 칸 0.35, 4번 칸 이후 0.2~0.5다 | 확실. 시간대 56개에서 같은 모양 |
| 보인 뒤 클릭률도 순서를 타나 | 방향은 내려가지만(2~3번 0.86배, 4~6번 0.60배, 7번 이후 0.32배) 구간이 1을 품어 못 가른다 | 아니오. 같은 배너가 여러 칸에 선 배너가 24장뿐이다 |
| 칸별 단순 클릭률(2~3번 3.92%, 1번 2.22%)을 순서 효과로 읽어도 되나 | 안 된다. 그 차이는 어떤 배너가 어느 칸에 섰는지의 차이다 | 확실. 배너 고정효과를 넣으면 2~3번이 1번을 못 이긴다 |

따라서 priority는 **누가 얼마나 보게 하느냐**를 정하는 손잡이로 실증됐다. 클릭률을 올리는 손잡이라는 증거는 아직 없다. 클릭 수는 노출 수를 따라가므로 잘 눌리는 배너를 앞에 두면 클릭이 는다는 것은 성립한다.

## 방법

- 데이터: PostHog `banner_impression`·`banner_click`, position=top, 최근 60일, 테스트 코호트와 봇과 개발 트래픽 제외.
- `slot` 속성은 2026-09-29부터 찍힌다. 그 전은 배너 보관 파일(`beggars-ops/archive`)과 운영 파일로 시간대별 순서를 복원했다. 옛 구조 파일 머리말과 `BannerCatalog`를 따라 priority(기본 999), 종료 시각, id 순으로 놓고 묶음은 한 장으로 접는다.
- 복원 정확도: 실제 슬롯이 있는 9/29~30의 102개 중 73개 일치(72%), 나머지는 1칸 어긋난다. 그 시간에 안 보인 배너(매진 등)를 못 걸러서다. 어긋남은 칸 효과를 0쪽으로 깎으므로 위 클릭률 배수는 실제보다 1에 가깝게 나온다.
- 클릭 ~ Poisson(노출 x 배너 x 칸)을 교대 최대우도로 맞추고 배너를 다시 뽑는 부트스트랩(300회)으로 구간을 냈다.

## 종류별 (칸 위치만 통제, 배너 고정효과 아님)

칸 묶음별 기대 클릭 대비 실제: 쿠팡 랜덤 2.15배, 요기요 1.50배, 쿠팡이츠 핫딜 1.11배, 배민 0.97배, 땡겨요 0.79배, 쿠팡 선착순 0.77배, 자사 0.47배. 자사(4장), 쿠팡 랜덤(2장), 요기요(6장)는 배너 수가 작아 방향만 본다. 5천원 미만 배너 4장은 클릭률 0.69%로 나머지(약 2.7%)의 4분의 1이다.
