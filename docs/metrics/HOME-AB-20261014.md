## 상세 1. 실험 설정과 집계 기준

- 메인 화면 비교 실험은 2026-10-05 00:00부터 방문자를 방문자 ID의 해시(같은 입력에 늘 같은 값을 내는 계산)로 반반 나눈다(`web/src/homeExperiment.js`).
  - 쿠폰 카드 안(`coupon`): 브랜드마다 대표 쿠폰 한 장을 접힌 카드로 보인다.
  - 기존 안(`old`): 브랜드 카드가 앱별 할인 칩을 펼쳐 보인다.
- 핵심 지표(전환, 링크 클릭, 재방문)는 tracker 저장소 `docs/superpowers/specs/2026-10-02-home-a-design.md` 6절이 미리 정했다.
- 모든 숫자는 원장(`events.jsonl`, 서버가 받은 행동 이벤트를 한 줄씩 쌓는 파일)에서 냈다. 행동 분석 서비스 PostHog의 숫자와 다르면 원장을 따른다(`docs/ANALYTICS.md`).
- 집계에서 뺀 방문자:
  - 개발자 접속(`dev` 표시)과 스스로 밝힌 자동 방문(`bot` 표시)
  - 배포 점검용 방문자(`v_deploycheck`)
  - 주소에 `?home=a`나 `?home=old`를 붙여 안을 강제로 고른 방문자 43명(`home_forced`)
  - 어느 안인지 기록이 한 번도 없는 방문자 36명
  - 동작 없이 이틀 동안 세션 145개를 연 자동 방문자 1명(`v_fa46ff74d778e5ba`, 근거는 상세 4-1)
- 방문자의 안은 그 방문자 이벤트에 마지막으로 실린 `props.home` 값이다.
- 기간별 표는 그 기간 안에서 일어난 이벤트만 센다. 두 기간에 걸쳐 온 방문자는 두 기간에 모두 든다.

| 지표 | 그 방문자에게 있어야 하는 것 |
|---|---|
| 전환 | 할인 링크 클릭(`offer_link_click`)이나 배너 클릭(`banner_click`) 한 번 이상 |
| 무동작 | 모든 세션(한 번 들어와서 나갈 때까지)에 동작이 없음. 화면 노출, 들어옴, 나감, 설문 노출, 알림 안내, 첫 방문 안내는 동작으로 치지 않는다 |
| 검색 | 검색어 확정(`brand_search_submitted`) |
| 필터, 분류 | 분류 바꾸기, 앱 거르기, 빠른 필터, 필터 시트 열기나 적용, 멤버십, 초기화 중 하나 |
| 재방문 | 서로 다른 날짜에 이틀 이상 방문 |

- 차이는 쿠폰 카드 안 비율에서 기존 안 비율을 뺀 퍼센트포인트(%p)다.
- 상대 차이는 쿠폰 카드 안 비율을 기존 안 비율로 나눈 뒤 1을 뺀 값이다.
- [HOME-AB-LOG.md](HOME-AB-LOG.md)의 2026-10-08 현황은 무동작과 재방문 정의를 적지 않아서, 이 문서 숫자와 이어 비교하지 않는다.

### 4-1. 기존 안의 방문자당 세션이 많았던 이유

`v_fa46ff74d778e5ba`를 자동 방문자로 본 근거:
- 2026-10-11 ~ 2026-10-12 이틀 동안 세션이 145개다.
- 이벤트는 들어옴, 나감, 노출뿐이고 누르거나 고른 기록이 없다.
- 네트워크 주소의 해시(`ipHash`)가 7개로 바뀌었다.

- 조건: 동작이 하나도 없고, 세션 40개 이상, 하루 평균 세션 20개 이상

- 문턱을 높게 둔 이유: 14일 동안 25번 와서 보기만 한 방문자처럼, 새 할인을 확인만 하고 가는 실제 사용자가 있다
