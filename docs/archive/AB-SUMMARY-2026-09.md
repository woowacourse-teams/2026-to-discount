# A/B 실험 요약 — 상단 바 A(펼침) vs B(시트) (2026-08-20 ~ 09-15)

대시보드 "A/B 테스트 - 옵션 설정"의 인사이트 8개를 이 한 장으로 갈음한다. 인사이트 정의는
`scripts/posthog_dashboards.py`에 남아 있고 대시보드도 남긴다(서비스 지표 대시보드에서는 뺀다).
숫자는 2026-09-20 PostHog 질의 결과(테스트 코호트·크롤러 제외).

## 무엇을 비교했나

```
A  앱 버튼 + 분류 캐러셀을 전부 펼침        (TopBarA.jsx)          ← 확정
B  검색 중심 바 + 분류 메뉴바 + 바텀시트     (MenuBar, FilterSheet)  ← 09-15 삭제
```
배정: `visitorId` FNV-1a 해시로 반반. 실험 뒤 `variant`는 항상 `a`.

## 결론(09-14 인계 문서 §4와 같다)

- 전환율은 같다. 그러나 **조건을 만지는 사람이 A에서 7%p 많고, 만진 사람은 전환율이 약 18%p 높다.** 시트에 감추면 "조건이 걸려 있다"는 사실 자체를 못 보고, 펼쳐두면 그 자리에서 푼다.
- 앱 필터는 눈에 보여야 쓴다(13.2% → 1.8%). 검색은 바 중앙에 두면 쓴다(3.3% → 6.3%) — 그래서 A를 확정하되 검색은 A 바에 합쳤다(09-16).
- 09-18 이후의 필터 시트(정렬·필터링)는 B의 시트와 다른 것이다: A 바 위에 **추가**로 두었고 자주 쓰는 셋(할인금액 높은순·최소주문 낮은순·랜덤쿠폰도 넣기)은 빠른 줄로 펼쳐 두었다. 이 실험의 교훈(감추면 안 쓴다)을 따른 배치다. 효과는 "기능 사용 — 정렬·필터 종류별" 인사이트로 본다.

## 한계
