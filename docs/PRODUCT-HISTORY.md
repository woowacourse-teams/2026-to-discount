## 3. 큰 흐름 세 가지

### ① 전환율은 8월 초가 정점이었다

```
08-04  45.9%   08-06  47.4%     ← 정점
...
08-18  20.6%   08-23  13.0%     ← 바닥
08-24  38.1%   08-26  30.5%     ← 부분 회복
```

47% → 13% → 30%. **홍보일에 오히려 오르는 날이 있다**(08-24 38.1%) — 유입 경로가 이미 "할인 찾는 사람"으로 걸러져 있어서다.

### ② 재방문은 계속 내려간다

```
코호트 주   D+1 복귀   7일내 복귀
07-27       10.0%      17.8%
08-03        8.5%      15.3%
08-10        4.9%      12.5%
08-17        4.2%      10.3%
```

**구성 탓이 아니다.** 첫날 앱으로 나간 사람만 놓고 봐도 14.8% → 6.2%로 떨어지고, 홍보일/평일을 갈라도 둘 다 떨어진다.

같이 무너진 것: **첫날 체류 37초 → 13초**, 첫날 무동작 41.9% → 63.9%.

**돌아올 이유도 줄었다** — 매주 새로 잡히는 (앱,브랜드) 조합이 111 → 47 → 69 → 40 → 11로 사실상 정체다. 초기엔 다시 오면 볼 게 늘어 있었다.

### ③ 절벽은 첫 방문 한 곳에만 있다

```
1일 이상  2,827명 → 다음날까지  16.3%
2일 이상    460명 →             50.0%
3일 이상    230명 →             65.2%
5일 이상    111명 →             79.3%
```

**두 번째 방문만 만들면 절반이 남고, 다섯 번째부터는 80%가 굳는다.**

## 4. 지금 쓰고 있는 지표와 그 함정

| 지표 | 정의 | 조심할 것 |
|---|---|---|
| 전환율 | 앱으로 나간 **사람** / 전체 사람 | 1인당 총합은 소수가 부풀린다. b갈래 115클릭 중 43이 한 사람이었다 |
| 무동작 이탈 | 세션에서 조작 이벤트 0 | 체류 중앙 3.8초 — 내용을 보기 전에 나간 것에 가깝다 |
| D+1 복귀 | 첫 방문 다음날 재방문 | 재방문의 42.6%가 다음날에 몰린다. 장기 휴면 복귀는 거의 없다 |
| 코호트 | 첫 방문일로 묶는다 | 활동일로 묶는 것과 답하는 질문이 다르다 |
| 체류 | `page_exit`의 `dwellMs` 합 | 커버리지 88.6% → 81.8%로 조금씩 준다 |

### 실제로 틀렸던 셋 — 같은 실수를 반복하지 않기 위해

**① 1인당 총합** — "b가 두 배 낫다"로 읽혔는데 전환율은 18.7% 대 18.1%(p=0.89)였다. 한 사람이 43번 눌렀다.

**② 순서 없는 퍼널** — "각 이벤트를 언젠가 했나"로 세면 흐름이 아니라 교집합이다. 같은 네 단계의 마지막 도달이 139명 / 81명 / 44명으로 갈렸다(순서 무시 / 시각순 / 같은 세션).

**③ 지표의 뜻이 바뀐 것을 못 따라감** — 08-19 개편을 "재방문자 전환 반토막(34.8%→18.0%)"으로 발표했다가 정정했다. 그 개편이 `banner_click`을 새로 만들었고, 그건 08-19 전에 구조적으로 0이다. 앱으로 나가는 모든 길로 다시 세면 **34.5% → 34.7%, 변화 없음**이었다.

> 전후 비교에서 지표를 고를 때 **"그 사이에 이 지표의 분자나 분모를 바꾼 배포가 있었나"**를 먼저 확인한다.

## 6. A/B — 판정 불가, 표본이 절반 모자란다

```
주       a(명) a전환    b(명) b전환    검정
07-27     36  38.9%     48  43.8%   p=0.66
08-03     30  50.0%     48  45.8%   p=0.72
08-10     34  17.6%     49  36.7%   p=0.059
08-17     94  23.4%    112  19.6%   p=0.51
08-24    396  34.3%    354  30.8%   p=0.30

누적  a 458명 40.4%  /  b 425명 42.6%   z=0.66  p=0.51
필요 표본: 갈래당 1,050명 (지금 458/425)
```

주마다 승자가 바뀐다(a→b→b→a→a). **전형적인 노이즈**다.

**현재 트래픽(하루 60~250명)으로는 상대 30% 이상 차이만 잡힌다.** 그보다 작은 개선은 A/B 대신 퍼널·경로로 판단해야 한다.
