# ADR-002. 에뮬레이터는 Android SDK, BlueStacks 아님

- 날짜: 2026-07-26
- 상태: **[ADR-009](ADR-009-real-device-over-emulator.md)로 대체됨 (2026-07-27)** — 목표 클라우드 인스턴스가 가상 기기를 못 돌리는 것으로 확인되어 이 판단의 핵심 근거("리눅스 서버 실행")가 성립하지 않는다. BlueStacks를 쓰지 않는다는 결론은 유효하다.

## 맥락

앱 자동화 수단으로 BlueStacks가 먼저 후보로 거론되었다. 한편 실행 환경 요구사항은 "로컬 Windows PC와 오라클 클라우드 리눅스 서버 어느 쪽에서도 동일하게 동작"이다.

## 판단

Android SDK의 `emulator`(헤드리스 실행)를 사용한다. BlueStacks는 채택하지 않는다.

## 근거

- **BlueStacks는 Windows/macOS 전용이다.** 리눅스 서버에서 실행할 수 없으므로 "양쪽 환경 동일 동작" 요구사항을 원천적으로 만족시키지 못한다.
- Android SDK 에뮬레이터는 Windows·리눅스 모두 지원하며, 어느 쪽이든 ADB 인터페이스가 동일하다. 따라서 캡처 코드가 환경에 따라 분기하지 않는다.
- 헤드리스(`-no-window`) 실행이 가능해 서버에 GUI가 없어도 된다.

## 위험

배민·쿠팡이츠는 결제를 다루는 앱이라 에뮬레이터/루팅 탐지(Play Integrity 등)로 실행이 차단될 수 있다. 이는 앱마다 다르므로 앱을 추가할 때마다 개별 검증이 필요하다. 차단되는 앱은 `ADR-008`의 수동 캡처 경로로 전환한다.

## 뒤집을 조건

Android SDK 에뮬레이터에서 대상 앱 다수가 탐지로 차단되고, BlueStacks에서는 동작하는 것이 확인될 때. 단 그 경우 리눅스 서버 실행을 포기하는 것이므로, 실행 환경 요구사항을 먼저 재확인해야 한다.
