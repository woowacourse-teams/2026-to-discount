# ADR-007. 요기요도 웹 분리 없이 앱 파이프라인으로 통합

- 날짜: 2026-07-26
- 상태: 확정

## 맥락

5개 앱을 브라우저로 전수 확인한 결과, **요기요만 로그인 없이 웹에서 매장 할인 배지를 볼 수 있었다**(예: 강남역 BHC-역삼점 `3,000원 할인`). 나머지 4개는 웹에 앱 다운로드 랜딩만 있다.

따라서 요기요는 웹 API로, 나머지는 앱으로 수집하는 이원 구조를 검토했다.

## 판단

요기요를 분리하지 않는다. 5개 앱 모두 동일한 앱 기반 파이프라인을 적용한다.

## 근거

- **웹에 노출되는 것이 앱에서 실제로 받는 혜택과 다르다.** 앱에서는 금액대별 쿠폰이 추가로 제공되므로, 웹만 보면 실제 할인을 과소 집계한다.
- **실제 구매 창구가 앱이다.** 비교의 기준은 사용자가 실제로 결제할 때 적용되는 조건이어야 한다.
- 경로를 이원화하면 캡처 계층이 두 종류가 되고, 요기요만 다른 실패 양상·다른 검증 방법을 갖게 된다. 앱 하나 아끼려고 파이프라인 전체의 균일성을 잃는 거래는 불리하다.

## 대가

요기요는 웹으로 하면 에뮬레이터 없이 간단히 되는데 그 이점을 버린다. 대신 5개 앱이 동일한 캡처·판독·전환 절차를 공유한다.

## 뒤집을 조건

요기요 앱이 에뮬레이터에서 동작하지 않고 수동 캡처도 부담스러운 경우, 웹 경로를 **보조 수단**으로 추가할 수 있다. 그 경우 레코드에 웹 출처임을 명시하고, 앱 전용 혜택이 누락된 값임을 대시보드에 표기해야 한다.
