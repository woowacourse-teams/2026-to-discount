# 요약

**판정: 살아남음 (2026-08-12 밤).** 층화 무작위 표본 30행 중 29행이 증거 화면 내용과 일치해 등록 기준(28건 이상)을 통과했다. 명명된 최대 위험이었던 단일 파일 24행 클러스터(`2026-08-03/baemin.jpg`)는 층화 표본 8행 전부 일치, 정상적인 8/3 배민 브랜드관 캡처로 확인됐다.

- **결정**: 보존군 111행(재연결 전부터 경로가 실존, 내용 검증이 없던 사각지대)을 이동군과 같은 "검증 가능한 증거" 등급으로 확정할 것인가.
- **가설(등록)**: 보존군의 증거 화면은 그 행의 내용을 담고 있다. 표본 30행에서 28건(93%) 미만 일치면 기각.
- **결과**: 29/30 일치. 불일치 1건(행 220)은 땡겨요 혜택탭 캡처가 쿠폰 카드 4장까지만 담겨 맘스터치 피자앤치킨이 화면에 없는 **커버리지 결손**이다. 같은 파일을 가리키는 표본 밖 3행(145, 154, 217)도 같은 유형으로 보인다(후속 확인).
- **다음 행동(persevere)**: 보존 291행에 검증 가능한 증거 등급을 부여하되, 커버리지 결손 행들은 확인 후 검증 불가 표시 대상에 포함한다(표시 방식 설계는 기존 미결과 병합).
- **의의**: 손상형이 아니라 커버리지 결손형 오염이 실증됐다. 원장 바이트로는 안 보이고 파일을 열어야 보인다는 점에서, 사고일 실험 닫음의 권고(내용 검증은 파일 내용 층에)를 실물로 뒷받침한다.

# 1 결정

**배경.** 오늘의할인 원장(`data/log.jsonl`, 363행)의 각 행은 증거 화면(그 행이 주장하는 할인의 근거 캡처)을 `screenshot_path`로 가리킨다. 2026-08-12 아침의 재연결 실험은 경로가 끊겼던 180행에 대해 "파일명이 실제 증거 화면을 가리킨다"를 표본 30행 눈가림 판독으로 검증했고(30/30 일치, 살아남음), 그 근거로 180행을 재연결해 보존율이 80.2%(291/363)가 됐다. 그런데 그 보존율은 경로 실존 기준이다. 경로가 처음부터 살아 있어 아침 실험의 표본 틀에 들어가지 않았던 111행은 내용 검증이 한 번도 없었다. 이 111행 중 24행이 파일 한 장(`ref/delivery/2026-08-03/baemin.jpg`)에 몰려 있어, 파일 하나의 오염이 곧 24행의 동시 붕괴다. 같은 날 저녁, 사고일 판별 실험(등록 전 닫음)의 탐사는 내용형 오염이 원장 바이트에 흔적을 남기지 않음을 확인했다. 즉 이 111행이 유효한 증거인지는 열어 보기 전에는 알 수 없다.

- **가르는 결정**: 보존군 111행을 이동군(표본 검증 완료)과 같은 "검증 가능한 증거" 등급으로 확정할 것인가.
- **결과별 행동**:
  - **살아남으면**: 보존 291행 전체에 같은 신뢰 등급을 부여한다. 원장 기반 분석은 표본 수준의 내용 검증을 얻는다. 다음 작업은 잔여 72행의 영구 검증 불가 표시 설계로 넘어가고, 파일 내용 층 검문은 예방 수준의 우선순위를 유지한다.
  - **반증되면**: 경로 실존과 증거 유효가 원장 안에서 실제로 어긋난다는 실증이므로, 오염 행을 식별해 검증 불가 표시를 확대하고, 원장 기반 분석의 신뢰 등급을 재조정하며, 파일 내용 층 검문(사고일 실험 닫음 기록의 권고)을 긴급으로 승격한다.

두 갈래의 후속 투자가 다르다.

# 3 가설

우리는 **보존군(재연결 전부터 경로가 실존한 111행)의 증거 화면이 그 행의 내용을 담고 있다**고 믿는다. **2026-08-13 안에** 층화 무작위 표본 30행을 눈가림 판독으로 대조했을 때 **파일 내용이 원장 행의 앱, 브랜드, 금액과 일치하는 비율**이 **30건 중 28건(93%)**을 넘지 못하면 이 믿음은 틀린 것이다.

**임계값 근거.** 아침 재연결 실험과 동일한 오염 허용 논리를 쓴다: 허용 오염 5%대, 표본 30행에서 2건까지. 판단이 섞인 수치임도 동일하게 밝힌다.

**표본 구성(등록 시 고정).** 층화 2층, 시드 2026081202.

- 층 1: `ref/delivery/2026-08-03/baemin.jpg` 참조 24행에서 8행. 사전에 명명된 위험 집중(한 파일 24행)이라 표본이 반드시 덮어야 한다. 비례 배분(6.5행)보다 소폭 가중한다.
- 층 2: 나머지 87행에서 22행.

**불일치 판정 기준.** 아침 실험 등록 기준과 동일하다. 다음 중 하나라도 해당하면 불일치: 화면에 원장 행의 브랜드가 없다, 브랜드는 있으나 금액이 원장과 다르다, 화면의 앱이 원장의 앱과 다르다, 화면이 빈 화면이거나 오류 화면이다, 화면을 판독할 수 없다. 날짜는 관측 불가로 판정에서 제외한다. 금액 대조의 정본은 `raw_text`(화면 원문)이며, `amount`와의 차이가 문서화된 정규화 정책(ADR-014, ADR-017)과 일치하면 불일치가 아니다.

# 4 설계

- **움직이는 변수(하나)**: 없음. 관측 실험이다.
- **통제**:
  - 표본은 등록된 층화와 시드로 뽑고, 뽑은 목록을 문서에 남긴 뒤 판독 후 변경하지 않는다.
  - 판독은 격리 서브에이전트가 맡는다. 판독자는 익명화 폴더명의 타일 이미지만 받고, 원장을 포함한 다른 프로젝트 파일 접근을 금지당한다. 전사 확정 후에만 원장 값을 꺼내 기계 대조한다.
  - **오케스트레이터 컨텍스트는 이미 오염돼 있다**: 같은 날 저녁 사고일 탐사에서 8/3 수집 행들의 원장 값(브랜드, 금액, 원문)을 열람했다. 따라서 이 실험의 눈가림 경계는 판독자 격리가 전담하며, 오케스트레이터의 역할은 기계 대조와 증거 기반 재확인으로 제한한다.
  - 타일 절단은 sips 함정(오프셋 0은 중앙 크롭, 플러시는 원본 전체)을 회피해 오프셋 1과 플러시-1을 쓰고, 절단 결과는 좌표 검산으로 확인한다.
  - 원장 파일에 쓰기를 하지 않는다.
- **비용 검산**: 표본 추출과 타일 스크립트 재사용 + 판독자 약 6명 + 대조, 2시간 내. 정보 가치는 보존 291행 신뢰 등급의 확정과 24행 클러스터의 생사다. 비용이 가치보다 명백히 작다.

# 6 갱신

- **다음 행동: persevere.** 결정 매핑대로 보존 291행 전체에 검증 가능한 증거 등급을 부여한다. 단 이번에 확인된 커버리지 결손을 함께 처리한다: 행 220과 같은 파일의 표본 밖 3행(145, 154, 217)을 전수 확인하고, 브랜드가 화면에 없는 행은 잔여 72행과 같은 검증 불가 표시 대상에 포함할 것을 제안한다(표시 방식 설계는 기존 미결과 병합).
- **배운 것**:
  1. 24행 클러스터(`baemin.jpg`)는 유효했다. 층화 표본 8행 전부 일치, 화면도 정상 8/3 배민 브랜드관 캡처였다. 파일 단위 동시 붕괴 위험은 이번에는 실현되지 않았고, 아침의 무효 파일 오판은 이중으로 반증됐다.
  2. 새 오염 유형이 나왔다: 손상이 아니라 **커버리지 결손**이다. 목록형 캡처 한 장이 여러 행의 증거일 때, 캡처의 스크롤 범위 밖 브랜드 행은 증거 연결이 끊긴다(행 220). 혜택탭 파일은 6행의 증거인데 화면에는 브랜드 4개뿐이다. 이 유형은 원장 바이트로 안 보이고 파일을 열어야만 보인다는 점에서, 사고일 실험 닫음의 구조 논증(내용형 사고는 파일 내용 층에서만 잡힌다)을 실물로 뒷받침한다.
  3. 앱 로고 없는 상세 화면의 앱 판정은 소극적일 수밖에 없다(다르다는 증거 없음 + 어휘 정합). 등록 기준이 "다르다"에만 걸려 운영 가능했지만, 적극 판별이 필요해지면 앱별 UI 지문(어휘, 색, 컴포넌트) 사전이 필요하다.
  4. 금액 정규화(ADR-017 8행, ADR-014 1행)가 표본 30행 중 9행의 대조 관건이었다. 정규화 정책을 모르는 대조자는 이 실험을 수행할 수 없다. 원문 보존과 정책 문서화가 실험 가능성의 전제다.
- **다음 가정**: 없음(실험 규모의 미검증 가정이 남지 않았다). 남은 것은 실험이 아니라 확인과 설계다: 혜택탭 잔여 3행 전수 확인(분 단위), 그리고 검증 불가 표시 방식 설계(미결, ADR 후보).
